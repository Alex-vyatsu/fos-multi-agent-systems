## Спецификация банка

| Параметр | Значение |
|---|---|
| Объём банка | не менее 40 заданий на модуль |
| Выборка в вариант | 10–15 заданий, время 20–30 мин ([формат КИМ-*.2](../../M3-game-theory/kim-02-test.md)) |
| Типы заданий | выбор одного ответа; выбор нескольких; верно/неверно; на соответствие; краткий открытый ответ; расчётное задание |
| Распределение по уровням | базовый (воспроизведение) — не более 50 %; средний (применение, сопоставление, расчёт) — не менее 50 % для модулей 3–5 |
| Покрытие тем | каждая тема (занятие) модуля представлена не менее чем 5 заданиями |
| Ключи | хранятся вместе с заданиями в закрытом контуре; в открытых материалах приводятся только образцы с пояснениями |
| Шкала | доля верных ответов → баллы: <55 % — 0; 55–69 % — 1; 70–84 % — 1.5; ≥ 85 % — 2 |

## Требования к добавлению и обновлению

- Каждое задание сопровождается: проверяемым индикатором, уровнем (Б/С), темой модуля, эталонным ответом и пояснением, почему неверные варианты неверны.
- Формулировка задания не должна допускать угадывания по длине или форме варианта; в заданиях с расчётом указываются единицы и требуемая точность.
- Задания, для которых ИИ-ассистент даёт готовый корректный ответ без понимания предмета, допустимы только как базовые: тест проводится без доступа к внешним источникам, при дистанционном формате — с прокторингом.
- **Ежегодное обновление:** не менее 20 % заданий банка заменяется или переформулируется; задания, показавшие долю верных ответов выше 95 % или ниже 20 %, пересматриваются.
- Изменения банка фиксируются в журнале версий банка в СДО с указанием даты, автора и причины.
