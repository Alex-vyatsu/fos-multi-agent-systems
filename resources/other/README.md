## Требования к добавлению

Размещайте здесь только материалы, которые нельзя содержательно отнести к другим разделам. Для каждого ресурса указывайте, какую задачу курса он решает и есть ли у обучающихся гарантированный доступ; ресурс без гарантированного доступа сопровождается указанием бесплатной альтернативы.
