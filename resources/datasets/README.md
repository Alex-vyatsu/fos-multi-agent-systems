# Датасеты

Дисциплина в основном работает не с готовыми выборками, а с **средами и генераторами данных**: мультиагентные среды, графы транспортных и коммуникационных сетей, потоки заявок. Для воспроизводимого старта в репозитории опубликованы локальный генератор и небольшой синтетический пример. Более крупные наборы создаются студентом или загружаются из перечисленных открытых источников.

## Требования к добавлению

- Указывайте источник, лицензию, объём, состав признаков (или структуру среды), ограничения и известные смещения.
- Для генераторов данных фиксируйте параметры и **seed**: без этого результат эксперимента невоспроизводим и не засчитывается (см. [приёмочные проверки](../../Exam/acceptance-checklist.md)).
- Персональные данные и сведения ограниченного доступа в репозиторий не помещаются; данные партнёров используются только в обезличенном виде и в объёме, разрешённом соглашением.
- Крупные файлы (свыше 10 МБ) в git не добавляются: используется внешнее хранилище или DVC со ссылкой в карточке ресурса.
- Для каждого набора данных указывайте, в каком КИМ он применяется и какое сравнение на нём проводится (базовый вариант, эталон, диапазон допустимых значений метрик).
