# Python-библиотеки и программные средства

Единое окружение курса фиксируется файлом `requirements.txt` (или `environment.yml`) в учебном репозитории и разворачивается в контейнере — это условие воспроизводимости, проверяемое на защите работ. Конкретные версии закрепляются перед началом семестра; ниже указано назначение, совместимость и лицензия каждого средства.

## Требования к добавлению

- Фиксируйте версию, команду установки, назначение, совместимость и лицензию; несовместимые по версиям библиотеки в одном окружении не смешиваются.
- Прежде чем добавлять новое средство, проверьте, не покрывается ли задача уже включённой библиотекой: окружение курса удерживается минимальным.
- Библиотека, требующая платной лицензии или недоступная обучающимся, включается только при наличии бесплатной альтернативы для выполнения того же КИМ.
- Для каждой библиотеки в учебных материалах приводится минимальный работающий пример; при обновлении мажорной версии пример проверяется заново.
