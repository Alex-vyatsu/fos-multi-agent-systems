# Информационные ресурсы

Раздел содержит учебно-методическое обеспечение дисциплины: литературу, научные публикации, программные средства, среды моделирования, банки заданий и правила работы с LLM-сервисами. Состав опирается на [РПД §7](../docs/rpd.md#7-учебно-методическое-обеспечение-дисциплины) и дополнен ресурсами, необходимыми для выполнения конкретных КИМ.

| Тип | Раздел | Назначение |
|---|---|---|
| Учебники | [textbooks](textbooks/README.md) | базовые и дополнительные учебные материалы |
| Научные статьи | [papers](papers/README.md) | современное состояние области и исследовательские задания |
| Банки тестов | [test-banks](test-banks/README.md) | текущий и рубежный контроль |
| Банки задач | [problem-banks](problem-banks/README.md) | практические, расчётные и кейсовые задания, варианты экзамена |
| Датасеты | [datasets](datasets/README.md) | учебные и проектные данные |
| Бенчмарки | [benchmarks](benchmarks/README.md) | сравнение методов и оценка качества |
| Python-библиотеки | [software/python-libs](software/python-libs/README.md) | программная реализация и автоматическая проверка |
| LLM и промпты | [llm-prompts](llm-prompts/README.md) | генерация, анализ и оценивание с применением БЯМ |
| Прочее | [other](other/README.md) | среды моделирования, онлайн-курсы, инфраструктура, сервисы |

## Единая карточка ресурса

| Поле | Что указать |
|---|---|
| Название | официальное название |
| Тип | учебник / статья / датасет / библиотека / сервис / промпт |
| Аннотация | 1–3 предложения |
| Связанные КИМ | относительные ссылки |
| Доступ | внутренняя или внешняя ссылка |
| Лицензия | условия использования |
| Дата проверки | ГГГГ-ММ-ДД |

## Регламент обновления

- **Дата проверки** в карточках означает дату последней сверки библиографического описания и назначения ресурса. Доступность внешних ссылок и актуальность версий подтверждает ответственный преподаватель **перед началом каждого семестра**; при изменении ссылки карточка обновляется с новой датой.
- Материалы, защищённые авторским правом, в репозиторий не размещаются: приводится библиографическое описание и способ легального доступа (ЭБС вуза, открытая публикация автора, сайт издателя).
- Банки тестовых заданий и эталонных решений **с ключами** хранятся в закрытом контуре (СДО вуза); в репозитории публикуется спецификация банка — см. [test-banks](test-banks/README.md) и [problem-banks](problem-banks/README.md).
- Новый ресурс добавляется вместе со ссылкой на КИМ, для которого он нужен; ресурсы, не связанные ни с одним КИМ, в раздел не включаются.
