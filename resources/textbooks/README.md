## Требования к добавлению

- Указывайте полное библиографическое описание: авторы, название, издательство, год, ISBN либо устойчивый URL.
- Не размещайте защищённые авторским правом файлы в репозитории — приводится описание и способ легального доступа (ЭБС вуза, открытая авторская версия, сайт издателя).
- Для каждого издания указывайте, какие модули и КИМ оно обеспечивает; учебник, не связанный ни с одним КИМ, в список не включается.
- Приоритет отдаётся источникам, доступным обучающимся бесплатно.
