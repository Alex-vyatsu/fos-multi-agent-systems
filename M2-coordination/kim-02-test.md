# КИМ-2.2. Тест по темам модуля 2

| Параметр | Значение |
|---|---|
| Модуль | 2. Координация, кооперация и коллективное принятие решений |
| Тип КИМ | Тест (задания с выбором ответа и с открытым кратким ответом) |
| Форма контроля | Текущий контроль |
| Проверяемые индикаторы | O-2.2, O-2.3 (уровень Б) — знаниевая компонента |
| Охват | Занятия 2.1 «Распределённое решение задач», 2.2 «Механизмы согласования» |
| Формат | 10–15 заданий; время 20–30 мин |

## 1. Назначение

Тест проверяет знаниевую компоненту индикаторов **O-2.2** и **O-2.3** на базовом уровне: механизмы координации/кооперации/конкуренции, протокол Contract Net, аукционы и переговоры, формирование коалиций, голосование и агрегирование предпочтений. Дополняет лабораторную работу [КИМ-2.1](kim-01-practical-work.md).

## 2. Структура и правила проведения

- Задания с выбором одного/нескольких верных ответов и с кратким открытым ответом.
- Проводится индивидуально письменно/в СДО вуза; при прохождении теста ИИ-ассистенты и внешние источники не допускаются, при дистанционном формате — прокторинг.
- Полный банк заданий с ключами — в [resources/test-banks](../resources/test-banks/README.md).

## 3. Примеры заданий

> Образцы для иллюстрации формата; рабочий вариант формируется из банка.

**1 (выбор одного).** В протоколе Contract Net агент, объявляющий задачу и выбирающий исполнителя, называется:
а) **менеджер (manager)**; б) контрактор; в) арбитр; г) медиатор.

**2 (последовательность).** Расположите этапы Contract Net по порядку: *объявление задачи → сбор предложений → выбор победителя → заключение контракта*.

**3 (выбор одного).** В аукционе второй цены (Викри) победитель платит:
а) свою ставку; б) **вторую по величине ставку**; в) среднюю ставку; г) фиксированную цену.

**4 (выбор нескольких).** Отметьте механизмы коллективного принятия решений в МАС:
- [x] голосование; [x] аукционы; [x] формирование коалиций; [ ] обратное распространение ошибки.

**5 (краткий ответ).** Назовите свойство механизма голосования, нарушение которого описывает парадокс Кондорсе. *(Ответ: транзитивность коллективного предпочтения.)*

## 4. Шкала оценивания

| Доля верных ответов | Баллы (в компоненте «тест») |
|---|:--:|
| < 55% | 0 (не зачтено) |
| 55–69% | 1 |
| 70–84% | 1.5 |
| ≥ 85% | 2 |

Тесты по всем модулям суммарно — до **10 баллов** компонента «текущий контроль» (см. [раздел 4 корневого README](../README.md#4-итоговая-оценка)).
