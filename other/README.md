# Другие материалы

Папка предназначена для вспомогательных информационных файлов, которые нельзя отнести к модулям, КИМ, методическим указаниям или ресурсам.

Для каждого добавленного файла укажите назначение, автора/источник, лицензию и связь с другими разделами репозитория.

## Содержимое

| Файл | Назначение | Автор / лицензия |
|---|---|---|
| [tools/check_links.py](tools/check_links.py) | Проверка внутренних markdown-ссылок и якорей: находит ссылки на несуществующие файлы и заголовки. Используется при заполнении [чек-листа качества](../docs/quality-checklist.md) | Команда разработки ФОС / CC BY 4.0 |
| [tools/check_weights.py](tools/check_weights.py) | Проверка согласованности рубрик: сумма весов критериев сверяется с заявленным максимумом баллов | Команда разработки ФОС / CC BY 4.0 |

Запуск из корня репозитория:

```bash
python other/tools/check_links.py
python other/tools/check_weights.py
```

Обе проверки не требуют зависимостей сверх стандартной библиотеки Python 3 и возвращают ненулевой код при обнаружении расхождений — их можно включить в проверку перед публикацией новой версии ФОС.

Скрипты являются вспомогательным инструментом сопровождения материалов, а не самостоятельным программным продуктом, поэтому распространяются на тех же условиях **CC BY 4.0**, что и остальные материалы репозитория. При добавлении значимого программного кода для него указывается отдельная программная лицензия — см. [примечание в LICENSE.md](../LICENSE.md#примечание-о-программном-коде).
