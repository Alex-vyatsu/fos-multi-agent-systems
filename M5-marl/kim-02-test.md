# КИМ-5.2. Тест по темам модуля 5

| Параметр | Значение |
|---|---|
| Модуль | 5. Мультиагентное обучение с подкреплением (MARL) |
| Тип КИМ | Тест (задания с выбором ответа и с открытым кратким ответом) |
| Форма контроля | Текущий контроль |
| Проверяемые индикаторы | ML-6.1, ML-6.3 (уровень С) — знаниевая компонента |
| Охват | Занятия 5.1 «Постановка MARL», 5.2 «Алгоритмы MARL», 5.3 «Надёжность и безопасность MARL» |
| Формат | 12–18 заданий; время 25–35 мин |

## 1. Назначение

Тест проверяет знаниевую компоненту индикаторов **ML-6.1** и **ML-6.3** на среднем уровне: постановка MARL, нестационарность среды, независимое обучение и его ограничения, CTDE, декомпозиция ценности (VDN, QMIX), MADDPG, метрики кооперации, компромисс «эффективность–безопасность», нарушенные режимы и безопасная деградация. Дополняет лабораторную работу [КИМ-5.1](kim-01-practical-work.md).

## 2. Структура и правила проведения

- Задания с выбором одного/нескольких ответов, на соответствие и с кратким открытым ответом.
- Проводится индивидуально письменно/в СДО вуза; при прохождении теста ИИ-ассистенты и внешние источники не допускаются, при дистанционном формате — прокторинг.
- Полный банк заданий с ключами — в [resources/test-banks](../resources/test-banks/README.md).

## 3. Примеры заданий

> Образцы для иллюстрации формата; рабочий вариант формируется из банка.

**1 (выбор одного).** Главная причина нестационарности среды в MARL:
а) шум датчиков; б) **одновременное изменение политик других обучающихся агентов**; в) большая размерность состояния; г) дискретизация времени.

**2 (выбор одного).** Парадигма CTDE означает:
а) децентрализованное обучение и централизованное исполнение; б) **централизованное обучение и децентрализованное исполнение**; в) полностью централизованную систему; г) обучение без вознаграждения.

**3 (соответствие).** Сопоставьте алгоритм и признак: VDN / QMIX / MADDPG ↔ «аддитивная декомпозиция ценности» / «монотонная декомпозиция ценности» / «actor-critic с централизованным критиком».

**4 (выбор нескольких).** Отметьте нарушенные режимы, проверяемые при оценке безопасности MARL:
- [x] отказ агента; [x] задержка/потеря связи; [x] дрейф среды; [ ] увеличение размера шрифта логов.

**5 (краткий ответ).** Как называется ограничение IQL, из-за которого независимо обучающиеся агенты воспринимают среду как нестационарную? *(Ответ: проблема нестационарности / отсутствие учёта политик других агентов.)*

## 4. Шкала оценивания

| Доля верных ответов | Баллы (в компоненте «тест») |
|---|:--:|
| < 55% | 0 (не зачтено) |
| 55–69% | 1 |
| 70–84% | 1.5 |
| ≥ 85% | 2 |

Тесты по всем модулям суммарно — до **10 баллов** компонента «текущий контроль» (см. [раздел 4 корневого README](../README.md#4-итоговая-оценка)).
