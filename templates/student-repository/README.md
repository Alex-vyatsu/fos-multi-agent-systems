# Шаблон учебного репозитория

Скопируйте структуру в личный репозиторий и заполните её по ходу работы.
Удалять историю не следует: последовательность небольших коммитов используется
на защите как одно из подтверждений самостоятельной работы.

```text
.
├── README.md
├── requirements.txt
├── src/
├── tests/
├── configs/
├── data/
├── results/
├── reports/
│   ├── architecture-decision.md
│   ├── experiment-log.csv
│   ├── report.md
│   └── ai-use-disclosure.md
└── prompts/
```

## Минимум для воспроизводимости

1. В корневом README указана одна команда запуска.
2. Версии Python и сторонних библиотек зафиксированы.
3. Конфигурации и seed не спрятаны внутри исходного кода.
4. Исходные данные либо включены, либо создаются одной документированной командой.
5. Выходные данные отделены от исходников.
6. Журнал экспериментов содержит успешные и неуспешные запуски.
7. Для значимого вывода приведены не менее трёх запусков и разброс результата.

Шаблоны отчётных файлов находятся рядом: [решение об архитектуре](architecture-decision.md),
[журнал экспериментов](experiment-log.csv), [основной отчёт](report.md) и
[декларация использования ИИ](ai-use-disclosure.md).
