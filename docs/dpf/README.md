# Рамки проектирования и воспроизводимости

Пакет версии `0.2.0` связывает предметную корректность мультиагентных систем с
практической готовностью ФОС к воспроизводимому применению.

> **Статус среза.** Этот каталог — неизменяемая методическая рамка и source
> snapshot, подготовленные до реализации итерации 1.2.0. Формулировки ниже об
> отсутствующих baseline/clean run описывают исходное состояние. Фактический
> статус текущего рабочего дерева, выполненные проверки и оставшиеся blockers
> находятся в [DPF-аудите](../dpf-audit-2026-07-27.md) и
> [отчёте итерации](../improvement-iteration-2026-07.md).

## Статус

Сам пакет пригоден для пилотной доработки и не является доказательством
выполнения backlog. Реализованные baseline, окружение, данные и clean run
подтверждаются только отдельными evidence текущей итерации. Пакет и эти
evidence не заменяют утверждение РПД, юридическую проверку либо назначение
ответственного.
