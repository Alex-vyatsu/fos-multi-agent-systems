# Словарь рамок по мультиагентным системам

**Редакция:** `0.2.0`  
**Назначение:** удерживать одинаковый смысл терминов в технической рамке и
прикладной рамке ФОС.

| Термин | Что это | Допустимое использование | Заблокированное прочтение | Прямой владелец смысла |
|---|---|---|---|---|
| Агент | Программный компонент, которому приписаны цели, возможности и граница действия | Участник задачи или взаимодействия | Обязательно LLM; обязательно автономен | Архитектура конкретной системы |
| LLM-агент | Агент, в решении которого используется LLM | Отдельный класс программных агентов | Любой вызов LLM является агентом | Архитектура и риск-профиль системы |
| Независимо управляемый агент | Агент с отдельным владельцем развертывания, политики или доверия | Определяет необходимость внешнего agent-to-agent контракта | Просто отдельный процесс внутри одного приложения | `MAS-P01`, A2A |
| Инструмент | Вызываемая операция или capability, доступная агенту/модели | MCP tool или локальный tool contract | Независимый агент с долгоживущей задачей | MCP или локальный API |
| Ресурс | Адресуемый контекст или данные для чтения/использования | MCP resource, dataset, документ | Разрешение изменить источник | MCP и владелец данных |
| Возможность | Объявление того, что агент или инструмент умеет делать | Discovery и предварительный выбор | Разрешение или доказанное качество | A2A Agent Card / OASF-профиль |
| Задача | Координационный объект с идентификатором, состоянием и результатом | Долгоживущая или внешняя работа | Одно транспортное сообщение | A2A task contract |
| Сообщение | Коммуникационный элемент в рамках взаимодействия | Запрос, уточнение, progress или ответ | Финальный артефакт по умолчанию | A2A/FIPA-контракт |
| Артефакт | Результирующий объект задачи | Отчет, файл, решение, structured result | Доказательство правильности только по факту наличия | Контракт задачи |
| Событие | Факт, опубликованный для подписчиков | CloudEvents envelope и доменный event | Полный жизненный цикл задачи | Доменный event contract |
| Идентичность | Проверяемое «кто/что» | Human, agent, workload, organization/tenant | Разрешение на действие | IAM |
| Делегирование | Ограниченное предоставление действия от имени другой стороны | Task/audience/scope/time-bound grant | Передача исходного токена без ограничений | IAM и `MAS-P04` |
| Полномочие | Разрешенный предел конкретного действия | Policy decision для ресурса и момента | Факт успешной аутентификации | IAM/policy owner |
| Автономность | Режим действия в заданном risk envelope | Назначается по классу действий | Постоянное свойство агента или один boolean | `MAS-P06` |
| Происхождение | Связи результата с использованными сущностями, действиями и ответственными сторонами | Воспроизведение и расследование | Доказательство истины | W3C PROV-O |
| Наблюдаемость | Эксплуатационные сигналы о поведении системы | Trace, metric, log, event | Полноценное audit evidence автоматически | Observability profile |
| Оценивание | Проверка поведения на объявленных сценариях и критериях | Component и end-to-end evaluation | Один универсальный score | `MAS-P08` |
| Воспроизводимость | Возможность повторить заявленный результат в закрепленных условиях | Clean run с версиями, seeds и acceptance | Равенство байтов при стохастическом алгоритме без оговорок | Протокол конкретной работы |
| Бейзлайн | Минимальная реализованная точка сравнения | Проверяемая отправная реализация | Эталон наилучшего качества | Владелец КИМ/эксперимента |
| КИМ | Контрольно-измерительный материал | Конкретное задание или форма контроля | Рубрика, ресурс или результат обучения | ФОС/РПД |
| Рубрика | Критерии и шкала оценивания | Оценка evidence items | Сам КИМ или модель измерения | Владелец контроля |
| Индикатор | Элемент КРМ, проверяемый дисциплиной | С точной исходной формулировкой и уровнем | Предметный дескриптор, отредактированный вместо исходного текста | КРМ |
| Предметный дескриптор | Конкретизация наблюдаемого действия в дисциплине | Отдельное поле рядом с индикатором | Новая формулировка индикатора КРМ | Команда дисциплины |
| Доказательство обучения | Конкретный наблюдаемый результат студента | Код, отчет, лог, защита, artifact | Название задания или сумма баллов | КИМ и рубрика |
| Ресурсный профиль | Набор доступных вычислительных и организационных условий | Minimum, recommended, extended | Неявное ожидание платного API/GPU | Владелец курса |
| Чистый запуск | Выполнение по опубликованной инструкции в новом окружении | Приемка воспроизводимости | Запуск в рабочей среде автора | Release/pilot protocol |
| Доступный ресурс | Ресурс, который целевой участник может получить на заявленных условиях | Открытый URL, включенный файл или явно управляемый закрытый доступ | Только упоминание ресурса | Владелец публикации |
| Сопровождающий | Назначенная роль, отвечающая за актуальность и выпуск | Triage, refresh, deprecation, release | Неопределенное «команда» без ответственного | Организация курса |

Новый термин добавляется только вместе с допустимым использованием,
заблокированным сильным прочтением и владельцем смысла.
