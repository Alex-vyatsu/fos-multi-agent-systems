## Негативные и recovery-сценарии

Автоматически подтверждены:

- отсутствующий dataset даёт явную команду восстановления генератором;
- неизвестная capability и недоступный агент отклоняются до делегирования;
- неподдерживаемая версия A2A отклоняется;
- истёкший grant завершает задачу ошибкой;
- MCP tool вне scope и недоступный tool не создают артефакт;
- cancel переводит незавершённую задачу в `canceled`;
- повтор с тем же effect key возвращает один артефакт без двойного эффекта,
  но повторно проверяет scope и остальные границы grant;
- экзаменационный отказ инструмента восстанавливается отдельным безопасным
  прогоном.
- опубликованные summary, trace и эксперимент повторно строятся без
  расхождений;
- IQL и VDN-style CTDE достигают согласованной политики на seeds 7/42/99;
- изменение масштаба 4/8/12 и паттерна не нарушает hard gates.

Ручных исправлений внутри чистой копии не выполнялось.

## Граница вывода

Протокол относится только к минимальному профилю на указанном окружении. Он не
подтверждает Docker build, рекомендуемый/расширенный профиль, промышленную
CTDE-реализацию, wire-conformance A2A/MCP или качество реальной LLM. Docker CLI
доступен, но daemon в среде проверки недоступен, поэтому контейнерный рецепт
остаётся структурно проверенным, но не квалифицированным запуском. Повторная
квалификация нужна после изменения примеров, tests, evidence, manifest,
runtime или Docker base image.
