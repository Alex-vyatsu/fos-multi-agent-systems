# КИМ-3.2. Тест по темам модуля 3

| Параметр | Значение |
|---|---|
| Модуль | 3. Теория игр и стратегическое взаимодействие агентов |
| Тип КИМ | Тест (задания с выбором ответа и с открытым кратким ответом) |
| Форма контроля | Текущий контроль |
| Проверяемые индикаторы | O-2.1, O-2.4 (уровень С) — знаниевая компонента |
| Охват | Занятия 3.1 «Игры и равновесия», 3.2 «Стохастические игры и механизм-дизайн» |
| Формат | 10–15 заданий; время 20–30 мин |

## 1. Назначение

Тест проверяет знаниевую компоненту индикаторов **O-2.1** и **O-2.4** на среднем уровне: матричные и повторяющиеся игры, равновесие Нэша и оптимальность по Парето, дилемма заключённого, стохастические игры, минимаксные мультиагентные алгоритмы, основы механизм-дизайна. Дополняет лабораторную работу [КИМ-3.1](kim-01-practical-work.md).

## 2. Структура и правила проведения

- Задания с выбором одного/нескольких ответов, на соответствие и с кратким открытым ответом; допускаются задания с небольшим расчётом (например, поиск равновесия в 2×2 игре).
- Проводится индивидуально письменно/в СДО вуза; при прохождении теста ИИ-ассистенты и внешние источники не допускаются, при дистанционном формате — прокторинг.
- Полный банк заданий с ключами — в [resources/test-banks](../resources/test-banks/README.md).

## 3. Примеры заданий

> Образцы для иллюстрации формата; рабочий вариант формируется из банка.

**1 (выбор одного).** Равновесие Нэша — это профиль стратегий, при котором:
а) суммарный выигрыш максимален; б) **ни одному игроку невыгодно в одностороннем порядке менять стратегию**; в) выигрыши игроков равны; г) исход оптимален по Парето.

**2 (верно/неверно).** «Любое равновесие Нэша оптимально по Парето». *(Неверно; контрпример — дилемма заключённого.)*

**3 (расчёт).** В игре 2×2 с матрицей выигрышей [приводится] укажите равновесие(я) Нэша в чистых стратегиях.

**4 (краткий ответ).** Назовите стратегию повторяющейся игры, которая на первом шаге кооперирует, а затем повторяет предыдущий ход соперника. *(Ответ: Tit-for-Tat.)*

**5 (выбор одного).** Основная задача механизм-дизайна:
а) обучить агента; б) **спроектировать правила игры так, чтобы рациональное поведение агентов вело к желаемому исходу**; в) найти кратчайший путь; г) кластеризовать данные.

## 4. Шкала оценивания

| Доля верных ответов | Баллы (в компоненте «тест») |
|---|:--:|
| < 55% | 0 (не зачтено) |
| 55–69% | 1 |
| 70–84% | 1.5 |
| ≥ 85% | 2 |

Тесты по всем модулям суммарно — до **10 баллов** компонента «текущий контроль» (см. [раздел 4 корневого README](../README.md#4-итоговая-оценка)).
