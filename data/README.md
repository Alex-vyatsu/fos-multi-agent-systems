# Исходные данные КРМ

## Файлы

| Файл | Назначение |
|---|---|
| [krm-v3.0.xlsx](krm-v3.0.xlsx) | исходная книга КРМ версии 3.0 (первоисточник, не редактируется) |
| [role-competency-matrix.csv](role-competency-matrix.csv) | матрица «роль × компетенция»: требуемые уровни КРМ (Б/С/П) для целевых ролей дисциплины |
| [competency-catalog.csv](competency-catalog.csv) | каталог формируемых компетенций и индикаторов с целевыми уровнями освоения в дисциплине |
| [indicator-evidence.csv](indicator-evidence.csv) | атомарная трассировка «индикатор → уровень → КИМ → evidence → строка рубрики → минимум → ресурсы» |
| [resource-manifest.csv](resource-manifest.csv) | адресуемый инвентарь критических локальных ресурсов минимального контура |

Файлы `.csv` являются производными от книги КРМ v3.0: в них перенесены только те коды, индикаторы и уровни, которые формируются данной дисциплиной «Мультиагентные системы». Кодировка — UTF-8 (с BOM для корректного открытия в Excel), разделитель — запятая.

### Схема `role-competency-matrix.csv`

`role, O-2, ML-6, LLM-4, FC-3, note` — по одной строке на роль; в ячейках компетенций указан требуемый уровень КРМ (`Б`/`С`/`П`, «—» — не требуется). Основная целевая роль — **ML Engineer**; также обслуживаются MLOps и AI Architect.

### Схема `competency-catalog.csv`

`competency_code, competency_name, competency_target_level, indicator_code, indicator_name, indicator_target_level` — по одной строке на индикатор. Целевые уровни дисциплины: O-2 — С, ML-6 — С, LLM-4 — Б, FC-3 — Б.

## Листы книги

| Лист | Содержание |
|---|---|
| `Роли-компетенции наглядно` | матрица компетенций и уровней для профессиональных ролей |
| `Роли - определения и функции` | определения ролей, трудовые действия, фокус и функции |
| `Профессиональные` | компетенции, индикаторы и дескрипторы уровней |
| `Опережающие профессиональные` | перспективные компетенции и индикаторы |
| `Отраслевые` | компетенции применения ИИ в отраслях |
| `Универсальные (надпроф.)` | этика, коммуникация, системное и критическое мышление |
| `Аббревиатуры разные` | справочные сокращения и обозначения |

## Правило использования

Не редактируйте исходную книгу при заполнении ФОС. Выбранные коды, индикаторы и уровни переносите в документы дисциплины, сохраняя исходную формулировку КРМ и добавляя отдельный предметный дескриптор.

После изменения КРМ, КИМ, рубрики или локального ресурса запустите
`python other/tools/check_traceability.py`. Расхождение точной формулировки,
уровня или ссылки блокирует общую проверку.
