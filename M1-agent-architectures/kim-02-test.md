# КИМ-1.2. Тест по темам модуля 1

| Параметр | Значение |
|---|---|
| Модуль | 1. Архитектуры агентов и мультиагентных систем |
| Тип КИМ | Тест (задания с выбором ответа и с открытым кратким ответом) |
| Форма контроля | Текущий контроль |
| Проверяемые индикаторы | O-2.1 (уровень Б) — знаниевая компонента |
| Охват | Занятия 1.1 «Агенты и МАС: основные понятия», 1.2 «Архитектуры и коммуникации» |
| Формат | 10–15 заданий; время 20–30 мин |

## 1. Назначение

Тест проверяет знаниевую компоненту индикатора **O-2.1** на базовом уровне: понятийный аппарат теории агентов и МАС, классификацию архитектур и способов коммуникации, границы применимости мультиагентного подхода. Тест дополняет лабораторную работу [КИМ-1.1](kim-01-practical-work.md), которая проверяет умения и владение.

## 2. Структура и правила проведения

- Задания двух форматов: с выбором одного/нескольких верных ответов и с кратким открытым ответом (термин, определение, соответствие).
- Проводится письменно/в СДО вуза (iSpring / ELMA365 или аналог) индивидуально.
- Использование ИИ-ассистентов и внешних источников **при прохождении теста не допускается** (контроль знаниевой компоненты); при дистанционном формате применяется прокторинг.
- Полный банк заданий с ключами и вариантами хранится в [resources/test-banks](../resources/test-banks/README.md).

## 3. Примеры заданий

> Ниже — образцы заданий для иллюстрации формата и уровня. Рабочий вариант формируется из банка заданий.

**1 (выбор одного).** Какое свойство агента означает способность действовать без прямого вмешательства человека?
а) реактивность; б) **автономность**; в) проактивность; г) социальность.

**2 (выбор нескольких).** Отметьте признаки, при которых мультиагентная архитектура предпочтительнее одноагентной:
- [x] задача естественно распределена между независимыми сущностями;
- [x] требуется устойчивость к отказу отдельных компонентов;
- [ ] задача сводится к единственному детерминированному вычислению;
- [x] среда динамична и частично наблюдаема.

**3 (соответствие).** Сопоставьте архитектуру и её характеристику: реактивная / делиберативная (BDI) / гибридная ↔ «стимул–реакция без внутренней модели» / «убеждения–желания–намерения» / «сочетание реактивного и планирующего слоёв».

**4 (краткий ответ).** Назовите стандарт языка межагентной коммуникации, разработанный FIPA. *(Ответ: FIPA ACL.)*

**5 (открытый).** В одном–двух предложениях укажите условие, при котором применение МАС **не** оправдано.

## 4. Шкала оценивания

Оценивание по ключу: доля верных ответов переводится в баллы теста.

| Доля верных ответов | Баллы (в компоненте «тест») |
|---|:--:|
| < 55% | 0 (не зачтено) |
| 55–69% | 1 |
| 70–84% | 1.5 |
| ≥ 85% | 2 |

Тесты по всем модулям суммарно дают до **10 баллов** компонента «текущий контроль» (см. [раздел 4 корневого README](../README.md#4-итоговая-оценка)).
