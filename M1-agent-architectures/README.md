# Модуль 1. Архитектуры агентов и мультиагентных систем

Модуль вводит понятия агента и мультиагентной системы, архитектуры агентов (реактивные, делиберативные, гибридные) и способы межагентной коммуникации, а также границы применимости МАС по сравнению с одноагентными и workflow-решениями.

**Объём:** 16 а.ч. (лекции — 4, ЛР — 4, СРС — 8).
**Формируемые индикаторы:** O-2.1 (целевой уровень модуля — Б).

## Связь с моделью измерения

Лабораторная работа проверяет способность обосновать применение МАС и реализовать простейший сценарий взаимодействия агентов (индикатор **O-2.1** на базовом уровне). Итоговый уровень O-2.1 (С) достигается в модуле 3 и на рубежном контроле; здесь закладывается базовый уровень. Полные дескрипторы — в [разделе 4 РПД](../docs/rpd.md#4-планируемые-результаты-обучения-дескрипторы-освоения-индикаторов-крм).
