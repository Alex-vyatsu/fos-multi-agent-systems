# Модуль 6. Мультиагентные системы на основе LLM

Модуль охватывает архитектуру мультиагентных LLM-систем (оркестратор и специализированные агенты; A2A — межагентное взаимодействие; MCP — подключение инструментов и контекста; память и ограничения LLM-контура), паттерны взаимодействия (ReAct, Plan-and-Solve — внутри агента; «планировщик–исполнитель», «критик», дебаты — между агентами) и построение ответственных, промышленно-эксплуатируемых МАС (ответственный контур и LLM-компоненты; валидация и трассировка; тайм-ауты, повторы, резервный сценарий, human-in-the-loop). LLM рассматривается как один из вариантов архитектуры МАС.

**Объём:** 22 а.ч. (лекции — 8, ЛР — 6, СРС — 8).
**Формируемые индикаторы:** LLM-4.1, LLM-4.3 (целевой уровень — Б); FC-3.3 (Б, в части работы с обзорами).

## Связь с моделью измерения

Лабораторная работа формирует базовый уровень индикаторов **LLM-4.1** (построение мультиагентной LLM-системы из готовых компонентов, разделение ответственного и LLM-контуров) и **LLM-4.3** (применение агентных паттернов). Обзорная записка развивает **FC-3.3**. Результаты работы (в т.ч. паспорт архитектурного решения) используются в практическом задании промежуточной аттестации. Полные дескрипторы — в [разделе 4 РПД](../docs/rpd.md#4-планируемые-результаты-обучения-дескрипторы-освоения-индикаторов-крм).
