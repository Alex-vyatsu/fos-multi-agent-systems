# Модуль 4. Роевой интеллект и метаэвристические алгоритмы

Модуль посвящён метаэвристикам коллективного поведения: методу роя частиц (PSO), муравьиному алгоритму (ACO), алгоритму пчелиной колонии; принципам самоорганизации; мультиагентному поиску и оптимизации на графах, критериям эффективности кооперации и метрикам самоорганизации, а также динамике сложных МАС (число агентов, плотность связей, локальные правила).

**Объём:** 20 а.ч. (лекции — 6, ЛР — 6, СРС — 8).
**Формируемые индикаторы:** O-2.2, O-2.4 (целевой уровень — С); FC-3.3 (Б, в части СРС — работа с исследованиями).

**Воспроизводимый старт:** [упрощённый PSO](../examples/m4_pso.py) сопоставляет результат роя с случайным поиском при одинаковом бюджете вычислений.

## Связь с моделью измерения

Лабораторная работа выводит на средний уровень индикаторы **O-2.2** (применение метаэвристических алгоритмов) и **O-2.4** (оценка результативности через метрики самоорганизации и сравнение с одноагентными методами). Исследовательская записка формирует базовый уровень **FC-3.3** — работу с актуальными исследованиями МАС. Итог модулей 4–5 закрепляется на [рубежном контроле 2](../Midterm-2/README.md). Полные дескрипторы — в [разделе 4 РПД](../docs/rpd.md#4-планируемые-результаты-обучения-дескрипторы-освоения-индикаторов-крм).
