# КИМ-4.1. Лабораторная работа «Метаэвристическая оптимизация»

| Параметр | Значение |
|---|---|
| Модуль | 4. Роевой интеллект и метаэвристические алгоритмы |
| Тип КИМ | Лабораторная работа с устной защитой |
| Форма контроля | Текущий контроль |
| Проверяемые индикаторы | O-2.2, O-2.4 (уровень С) |
| Трудоёмкость | 6 а.ч. (ЛР) + подготовка в СРС 4 |
| Максимальный балл | 5 (см. [rubric-01.md](rubric-01.md)); минимум для зачёта — 3 |

## 1. Назначение и проверяемые результаты обучения

Лабораторная работа проверяет средний уровень индикаторов **O-2.2** (применение и настройка метаэвристических мультиагентных алгоритмов) и **O-2.4** (оценка результативности с учётом эффекта самоорганизации). По итогам обучающийся:

- **знает** алгоритмы роевого интеллекта (PSO, ACO, пчелиный), принципы самоорганизации, метрики эффективности кооперации;
- **умеет** реализовать и настроить метаэвристический алгоритм для задачи коллективной оптимизации, разработать метрики самоорганизации;
- **владеет** навыком экспериментальной оценки МАС и сопоставления с одноагентными и традиционными методами.

## 2. Условия выполнения

- **Среда и инструменты:** Python 3; NumPy/`scipy`; при желании готовые реализации (`pyswarms`, `ACO`-библиотеки) или собственная реализация; matplotlib для визуализации сходимости.
- **Форма работы:** индивидуально, по назначенному варианту.
- **Артефакты ведутся в Git:** код, конфигурация, журнал экспериментов, инструкция запуска.
- **Регламентированное использование ИИ-ассистентов** — при выполнении условий раздела 6.

## 3. Задание

1. **Постановка задачи оптимизации.** Задать задачу коллективной оптимизации по варианту (непрерывная функция / комбинаторная задача на графе).
2. **Реализация метаэвристики.** Реализовать/настроить PSO **или** ACO (по варианту); обеспечить журналирование поведения роя (позиции/феромоны, лучшее решение по итерациям).
3. **Метрики самоорганизации (O-2.4).** Ввести метрики: скорость и качество сходимости, разнообразие популяции, устойчивость к начальным условиям, эффект самоорганизации (улучшение относительно независимого поведения агентов).
4. **Сравнение с одноагентным методом.** Сопоставить с базовым одноагентным/традиционным методом (случайный/жадный поиск, градиентный спуск, полный перебор на малой задаче) по введённым метрикам.
5. **Динамика МАС.** Провести серию запусков при изменении числа агентов и/или плотности связей/локальных правил; проанализировать масштабные и нелинейные эффекты.
6. **Выводы.** Оценить, когда метаэвристика оправдана, и какова цена самоорганизации.

## 4. Индивидуализация (примеры вариантов)

| № | Задача | Алгоритм | Что варьируется |
|:--:|---|---|---|
| 1 | Минимизация многоэкстремальной функции (Растригин, Швефель) | PSO | Число частиц, инерционный вес |
| 2 | Задача коммивояжёра (малая/средняя) | ACO | Число муравьёв, испарение феромона |
| 3 | Маршрутизация на графе | ACO | Плотность графа |
| 4 | Размещение ресурсов | PSO / пчелиный | Топология соседства частиц |

Иные варианты — по согласованию с преподавателем при сохранении набора артефактов.

## 5. Требования к результату и формат сдачи

Обучающийся предъявляет: код и конфигурацию; журнал экспериментов; таблицу метрик и сравнение с одноагентным методом; результаты серии запусков при изменении масштаба; визуализацию сходимости; выводы. **Формат сдачи:** коммит(ы) в учебный репозиторий + устная защита.

## 6. Живая защита и правила использования ИИ и внешних ресурсов

- Защита **устная**: обучающийся воспроизводит результат и **на месте изменяет параметр** (число агентов, коэффициент испарения/инерции, размер задачи), объясняя влияние на сходимость и самоорганизацию.
- Вопросы на понимание механизма самоорганизации и различия метаэвристики и одноагентного метода.
- Репозиторий — артефакт, но не достаточное доказательство самостоятельного понимания.
- ИИ-ассистенты — при обязательном указании промптов и критическом анализе.

## 7. Критерии и шкала оценивания

Оценивание — по [рубрике `rubric-01.md`](rubric-01.md). Работа засчитывается при итоге не ниже **3 из 5** баллов и успешной живой защите.
