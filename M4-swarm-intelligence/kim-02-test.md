# КИМ-4.2. Тест по темам модуля 4

| Параметр | Значение |
|---|---|
| Модуль | 4. Роевой интеллект и метаэвристические алгоритмы |
| Тип КИМ | Тест (задания с выбором ответа и с открытым кратким ответом) |
| Форма контроля | Текущий контроль |
| Проверяемые индикаторы | O-2.2, O-2.4 (уровень С) — знаниевая компонента |
| Охват | Занятия 4.1 «Метаэвристики коллективного поведения», 4.2 «Мультиагентный поиск и оптимизация» |
| Формат | 10–15 заданий; время 20–30 мин |

## 1. Назначение

Тест проверяет знаниевую компоненту индикаторов **O-2.2** и **O-2.4** на среднем уровне: алгоритмы роевого интеллекта (PSO, ACO, пчелиный), принципы самоорганизации, мультиагентный поиск на графах, критерии эффективности кооперации и метрики самоорганизации. Дополняет лабораторную работу [КИМ-4.1](kim-01-practical-work.md).

## 2. Структура и правила проведения

- Задания с выбором одного/нескольких ответов, на соответствие и с кратким открытым ответом.
- Проводится индивидуально письменно/в СДО вуза; при прохождении теста ИИ-ассистенты и внешние источники не допускаются, при дистанционном формате — прокторинг.
- Полный банк заданий с ключами — в [resources/test-banks](../resources/test-banks/README.md).

## 3. Примеры заданий

> Образцы для иллюстрации формата; рабочий вариант формируется из банка.

**1 (выбор одного).** В методе роя частиц (PSO) движение частицы определяется её собственным лучшим положением и:
а) градиентом функции; б) **лучшим положением роя (или соседей)**; в) температурой отжига; г) феромоном.

**2 (выбор одного).** В муравьином алгоритме (ACO) вероятность выбора ребра растёт с увеличением:
а) длины ребра; б) **концентрации феромона на ребре**; в) числа итераций; г) размерности задачи.

**3 (соответствие).** Сопоставьте параметр и алгоритм: инерционный вес / коэффициент испарения феромона / радиус соседства ↔ PSO / ACO / PSO.

**4 (краткий ответ).** Назовите свойство МАС, при котором сложное коллективное поведение возникает из простых локальных правил без централизованного управления. *(Ответ: самоорганизация / эмерджентность.)*

**5 (выбор нескольких).** Отметьте метрики оценки эффекта самоорганизации:
- [x] скорость сходимости; [x] улучшение относительно независимого поведения агентов; [x] разнообразие популяции; [ ] число строк кода.

## 4. Шкала оценивания

| Доля верных ответов | Баллы (в компоненте «тест») |
|---|:--:|
| < 55% | 0 (не зачтено) |
| 55–69% | 1 |
| 70–84% | 1.5 |
| ≥ 85% | 2 |

Тесты по всем модулям суммарно — до **10 баллов** компонента «текущий контроль» (см. [раздел 4 корневого README](../README.md#4-итоговая-оценка)).
